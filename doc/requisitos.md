# Documento de Requisitos – CP2 FIT

## Requisitos Funcionais

### RF 01 – Cadastro de Usuários

O sistema deve permitir que novos usuários realizem seu cadastro, informando os dados solicitados, como nome de usuário, e-mail e senha.

### RF 02 – Autenticação de Usuários

O sistema deve permitir que os usuários realizem login utilizando suas credenciais, garantindo o acesso às funcionalidades de acordo com seu perfil.

### RF 03 – Gerenciamento de Matrículas

O sistema deve permitir que os alunos realizem sua matrícula na academia, selecionando o plano disponível e informando os dados necessários para a contratação.

### RF 04 – Controle de Acesso

O sistema deve restringir o acesso às funcionalidades de acordo com o tipo de usuário, diferenciando alunos, professores e administradores.

### RF 05 – Consulta de Modalidades

O sistema deve permitir que os usuários consultem as modalidades oferecidas pela academia.

### RF 06 – Gerenciamento de Modalidades

O sistema deve permitir que administradores cadastrem, consultem, editem e excluam modalidades disponíveis na academia.

### RF 07 – Gerenciamento de Aulas

O sistema deve permitir que administradores e professores cadastrem, consultem, editem e excluam aulas, informando a modalidade, o professor responsável e o horário.

### RF 08 – Gerenciamento de Turmas

O sistema deve permitir que administradores e professores gerenciem as turmas, associando professores, modalidades e horários.

### RF 09 – Inscrição em Turmas

O sistema deve permitir que alunos matriculados realizem inscrições nas turmas disponíveis e cancelem suas inscrições quando necessário.

### RF 10 – Consulta de Alunos nas Turmas

O sistema deve permitir que professores e administradores visualizem os alunos inscritos em cada turma, respeitando as permissões de acesso.

### RF 11 – Gerenciamento de Planos de Treino

O sistema deve permitir que professores e administradores criem e gerenciem planos de treino destinados aos alunos.

### RF 12 – Cadastro de Exercícios

O sistema deve permitir que professores e administradores adicionem exercícios aos treinos, organizando as atividades físicas de cada aluno.

### RF 13 – Consulta de Treinos

O sistema deve permitir que os alunos visualizem seus planos de treino e consultem os exercícios disponibilizados pelos professores.

### RF 14 – Gerenciamento de Usuários

O sistema deve permitir que administradores consultem, cadastrem, editem e excluam usuários da plataforma.

### RF 15 – Gerenciamento de Professores

O sistema deve permitir que administradores cadastrem e gerenciem os professores responsáveis pelas aulas e pelos planos de treino.

## Requisitos Não-Funcionais

### RNF 01 – Usabilidade

O sistema deve possuir uma interface intuitiva, organizada e de fácil utilização, permitindo que alunos, professores e administradores utilizem suas funcionalidades sem dificuldades.

### RNF 02 – Segurança

O sistema deve proteger os dados dos usuários por meio de autenticação, armazenamento seguro de senhas e controle de permissões de acesso.

### RNF 03 – Desempenho

O sistema deve apresentar tempo de resposta adequado durante a navegação e a execução de operações, evitando lentidão excessiva.

### RNF 04 – Compatibilidade

O sistema deve funcionar corretamente nos principais navegadores modernos, como Google Chrome, Microsoft Edge e Mozilla Firefox.

### RNF 05 – Integridade dos Dados

O sistema deve garantir que as informações cadastradas sejam armazenadas corretamente no banco de dados, evitando inconsistências e registros inválidos.

### RNF 06 – Manutenibilidade

O código-fonte deve ser organizado e estruturado de maneira que facilite futuras alterações, correções e implementações de novas funcionalidades.

### RNF 07 – Controle de Acesso

O sistema deve garantir que cada usuário tenha acesso somente às funcionalidades permitidas para seu respectivo perfil.

### RNF 08 – Disponibilidade

O sistema deve estar disponível para utilização sempre que o servidor e os serviços necessários estiverem em funcionamento.
